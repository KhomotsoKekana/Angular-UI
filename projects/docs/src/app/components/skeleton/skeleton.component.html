Skeleton Component

A placeholder loading state that can be used while content is being loaded. The skeleton component uses a pulsing animation to indicate a loading state.

Usage

<!-- Basic skeleton -->
<flex-skeleton class="w-full h-6 rounded"></flex-skeleton>

<!-- Multiple skeletons for text content -->
<div class="space-y-2">
  <flex-skeleton class="w-full h-4 rounded"></flex-skeleton>
  <flex-skeleton class="w-3/4 h-4 rounded"></flex-skeleton>
  <flex-skeleton class="w-1/2 h-4 rounded"></flex-skeleton>
</div>

<!-- Donut chart skeleton -->
<flex-skeleton type="donut-chart" class="w-40 h-40"></flex-skeleton>

<!-- Conditional skeleton loading state -->
<div *ngIf="isLoading; else loadedContent">
  <flex-skeleton class="w-full h-24 rounded"></flex-skeleton>
</div>
<ng-template #loadedContent>
  <!-- Your actual content -->
</ng-template>

Component Properties

Property Type Default Description
class string '' Custom Tailwind CSS classes to style the skeleton (width, height, rounded, etc.)
type 'default' | 'donut-chart' 'default' Type of skeleton to display

Accessibility

The skeleton component includes proper accessibility attributes:

  • Uses role="status" to indicate changing content
  • Includes aria-label to describe the loading state
  • Provides screen reader text with sr-only class

Design Guidelines

  • Use skeletons to indicate loading content rather than spinner for better perceived performance
  • Match the skeleton shape as closely as possible to the actual content that will load
  • Combine multiple skeletons to create complex loading states
  • Avoid using skeleton loaders for quick operations (less than 300ms)
