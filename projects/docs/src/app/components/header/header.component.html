Header Component

The <flex-header> is a highly versatile container designed for building various header structures. It utilizes named content projection slots: <flex-header-left>, <flex-header-center>, and <flex-header-right>, allowing for precise placement and complex layouts of your header content.

Component Properties (<flex-header>)

Property Type Default Description
class string '' (empty string) Standard Angular property. Allows custom CSS classes (e.g., Tailwind CSS) to be applied directly to the host <flex-header> element for flexible styling and layout control (like padding, background, flex properties, etc.).

Content Projection Slots

The header component uses named slots for precise content placement. Wrap your HTML or Angular components within these custom elements inside <flex-header>:

<flex-header-left> ... </flex-header-left>

Content placed here will be aligned to the left side of the header.

<flex-header-center> ... </flex-header-center>

Content placed here will be aligned to the center of the header.

<flex-header-right> ... </flex-header-right>

Content placed here will be aligned to the right side of the header.

The header component internally uses flexbox to arrange these slots. You have full control over the appearance and layout of the content within each slot using standard HTML and CSS (Tailwind CSS is heavily utilized in these examples). The class property on the <flex-header> itself can be used to control the alignment of these slots (e.g., items-center).
