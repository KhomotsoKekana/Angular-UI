Header Component

The <app-header> is a highly versatile container designed for building various header structures. It utilizes named content projection slots: <app-header-left>, <app-header-center>, and <app-header-right>, allowing for precise placement and complex layouts of your header content.

1. Simple Title Header

A straightforward header, often used for page titles or simple section headings, with the title occupying the central area.

Page Title

 
<app-header class="py-3">
  <app-header-center>
    <h1 class="text-xl font-medium text-gray-700">Page Title</h1>
  </app-header-center>
</app-header>

Component Properties (<app-header>)

Property Type Default Description
class string '' (empty string) Standard Angular property. Allows custom CSS classes (e.g., Tailwind CSS) to be applied directly to the host <app-header> element for flexible styling and layout control (like padding, background, flex properties, etc.).

Content Projection Slots

The header component uses named slots for precise content placement. Wrap your HTML or Angular components within these custom elements inside <app-header>:

<app-header-left> ... </app-header-left>

Content placed here will be aligned to the left side of the header.

<app-header-center> ... </app-header-center>

Content placed here will be aligned to the center of the header.

<app-header-right> ... </app-header-right>

Content placed here will be aligned to the right side of the header.

The header component internally uses flexbox to arrange these slots. You have full control over the appearance and layout of the content within each slot using standard HTML and CSS (Tailwind CSS is heavily utilized in these examples). The class property on the <app-header> itself can be used to control the alignment of these slots (e.g., items-center).
