Properties

Property Type Default Description
label string '' The label text for the input
type string 'text' HTML input type (text, password, email, number, date, etc.)
placeholder string '' Placeholder text when the input is empty
value string | number | Date '' Current input value, supports two-way binding
disabled boolean false Whether the input is disabled
error string | null null Error message to display below the input
leadingIcon string | null null Icon name to show at the start of the input
leadingText string | null null Text to display at the start of the input
trailingIcon string | null null Icon name to show at the end of the input
trailingButton string | null null Text for a button to show at the end of the input
enablePasswordReveal boolean false Whether to show a button to toggle password visibility
regex undefined Regular expression pattern for validation with error message
