Usage

<!-- Basic usage -->
<flex-spinner></flex-spinner>

<!-- With custom properties -->
<flex-spinner 
  size="lg"
  color="primary"
  speed="fast"
  variant="linear">
</flex-spinner>

<!-- In a loading state context -->
<div *ngIf="isLoading" class="flex justify-center">
  <flex-spinner></flex-spinner>
</div>

Properties

Property Type Default Description
size 'xs' | 'sm' | 'md' | 'lg' | 'xl' 'md' Controls the size of the spinner
color 'blue' | 'green' | 'red' | 'gray' | 'yellow' | 'primary' 'blue' Sets the color of the spinner
speed 'slow' | 'normal' | 'fast' 'normal' Controls the rotation speed of the spinner
variant 'default' | 'linear' 'default' Determines the visual style of the spinner

Accessibility Notes

  • The spinner includes role="status" to inform assistive technologies of its purpose
  • A visually hidden "Loading..." text is included for screen readers
  • Consider adding additional context when using spinners to inform users what is loading
  • Avoid using spinners that take up the entire viewport without providing feedback on what's happening
