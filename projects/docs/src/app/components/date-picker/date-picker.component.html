Date Picker Component

A flexible date picker component for selecting date ranges. Features include preset ranges, custom range selection, dual-calendar view, and time selection.

Available Preset Ranges

The date picker comes with several built-in preset ranges for quick selection:

  • Last hour
  • Last 6 hours
  • Last 12 hours
  • Today
  • Yesterday
  • Last 7 days
  • Last 14 days
  • Month to date
  • Last 3 months
  • Last 12 months
  • Custom range

Properties

Property Type Default Description
fromDate Date | null null Start date of the selected range
toDate Date | null null End date of the selected range
placement 'top' | 'bottom' | 'left' | 'right' 'bottom' Position of the dropdown relative to the trigger
showTimePicker boolean false Whether to show time input fields

Events

Event Type Description
dateRangeSelected Emitted when a date range is selected or a preset is chosen

Features

  • Dual-calendar month view for easier range selection
  • Built-in preset date ranges for quick selection
  • Custom date range selection
  • Optional time selection
  • Visual highlighting of the selected range
  • Configurable dropdown placement
  • Internationalization support through Angular's TranslateModule
  • Works with both mouse and keyboard navigation

Accessibility

The Date Picker component follows accessibility best practices:

  • Keyboard navigation support for calendar navigation and selection
  • Screen reader friendly with appropriate ARIA attributes
  • Focus management for improved keyboard usability
  • High contrast visual indicators for selection states
