Tab Group Component

A tabbed navigation component that organizes content into different tabs that can be switched between. The tab-group component provides multiple styling variants, orientation options, and responsive behavior.

Responsive Behavior

The Tab Group component automatically switches to a dropdown menu on mobile devices. Resize your browser window to see this behavior in action.

Tab Properties

Property Type Default Description
id string required Unique identifier for the tab
label string required Display text for the tab
icon string undefined Icon to display before the tab label
disabled boolean false Whether the tab is disabled
hidden boolean false Whether the tab should be hidden
translationKey string undefined Translation key for internationalization
hideInMobile boolean false Whether to hide the tab in mobile view

Component Properties

Property Type Default Description
tabs Tab[] [] Array of tab configurations
activeTabId string | null null ID of the currently active tab
orientation 'horizontal' | 'vertical' 'horizontal' Layout orientation of the tabs
variant 'default' | 'minimal' | 'button' | 'pills' | 'underlined' 'default' Visual style variant for the tabs
showIcons boolean true Whether to show icons in tabs if present
responsive boolean true Whether to convert to dropdown on mobile

Events

Event Type Description
tabChange EventEmitter<Tab> Emitted when the selected tab changes

Accessibility

The Tab Group component follows accessibility best practices:

  • Uses proper ARIA attributes (role="tablist", aria-selected, aria-disabled)
  • Supports keyboard navigation with proper tabIndex handling
  • Provides visual indicators for active, hover, and focus states
