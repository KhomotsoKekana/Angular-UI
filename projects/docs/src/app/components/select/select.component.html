Properties

Property Type Default Description
placeholder string 'Select an option' Text displayed when no item is selected
enableSearch boolean false Enables search functionality within the select
isDynamicSearch boolean false Disables client-side filtering, useful for server-side filtering
loading boolean false Whether the select is in a loading state
disabled boolean false Whether the select is disabled
icon string '' Icon to display in the select
innerClass string '' Additional classes for the inner select element
placement 'top' | 'bottom' | 'left' | 'right' 'bottom' Dropdown menu placement relative to the select
maxSelectionDisplay number 2 Max number of selected items to display before showing "+X more"
maxSelection number | null null Maximum number of items that can be selected. Null means unlimited.
selectedItems Array [] Array of currently selected items
selectionChange EventEmitter<any[]> - Emitted when selection changes, with an array of selected keys

Events

Event Payload Description
selectionChange Emitted when an item is selected
searchValueChange string Emitted when the search input changes
change Emitted when selection changes (alias for selectionChange)
onClose void Emitted when the dropdown closes
