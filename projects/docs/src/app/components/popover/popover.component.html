Popover Component

Usage

<!-- Basic Popover -->
<flex-popover>
  <flex-popover-trigger>
    <flex-button>Open Popover</flex-button>
  </flex-popover-trigger>
  <flex-popover-content>
    <div class="p-4">Popover content goes here</div>
  </flex-popover-content>
</flex-popover>

<!-- Controlled Popover with Events -->
<flex-popover 
  [isOpen]="popoverOpen"
  (open)="handleOpen()"
  (close)="handleClose()">
  <flex-popover-trigger>
    <flex-button (click)="popoverOpen = !popoverOpen">Toggle</flex-button>
  </flex-popover-trigger>
  <flex-popover-content>
    <div class="p-4">Controlled popover content</div>
  </flex-popover-content>
</flex-popover>

<!-- Customized Popover -->
<flex-popover 
  [placement]="'top'"
  [showArrow]="true" 
  [showCloseButton]="true"
  [backdropClose]="false">
  <!-- Trigger and content -->
</flex-popover>

Component Properties

Property Type Default Description
placement 'top' | 'bottom' | 'left' | 'right' 'bottom' Position of the popover relative to the trigger element
showCloseButton boolean false Whether to show a close button in the popover
showArrow boolean false Whether to show an arrow pointing to the trigger
offset number 10 Distance between the trigger and the popover in pixels
isOpen boolean | undefined undefined Controls the popover's open state (optional external control)
triggerId string undefined ID of an external trigger element
backdropClose boolean true Whether to close the popover when clicking outside
bgColor string '#FFFFFF' Background color of the popover
disabled boolean false Whether the popover functionality is disabled

Events

Event Type Description
open EventEmitter<void> Emitted when the popover is opened
close EventEmitter<void> Emitted when the popover is closed
