Avatar Component

A component to display user profile pictures or fallback initials.

Sizes

Variants

With Status

Fallback with Initials

Usage

<!-- With image -->
<app-avatar 
  src="https://example.com/avatar.jpg" 
  alt="User Avatar" 
  size="md" 
/>

<!-- With name fallback (generates initials) -->
<app-avatar 
  name="John Doe" 
  variant="primary" 
/>

<!-- With status indicator -->
<app-avatar 
  src="https://example.com/avatar.jpg" 
  status="online" 
/>

Properties

Property Type Default Description
src string | undefined undefined URL for the avatar image
alt string 'Avatar' Alternative text for accessibility
size 'sm' | 'md' | 'lg' 'md' Size of the avatar
name string | undefined undefined Full name for generating fallback initials
status 'online' | 'offline' | undefined undefined Optional status indicator
variant 'primary' | 'secondary' | 'primaryGhost' 'secondary' Color variant of the avatar
