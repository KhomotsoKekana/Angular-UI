Inputs

Input Type Default Description
isOpen boolean false Controls the visibility of the drawer
position 'top' | 'bottom' | 'left' | 'right' 'right' Determines which side of the screen the drawer appears from
size number 450 Default width (for left/right) or height (for top/bottom) of the drawer in pixels
minSize number 150 Minimum size when resizing
maxSize number 800 Maximum size when resizing
resizable boolean false Whether the drawer can be resized via drag handle
enableBackdrop boolean true Whether to show a backdrop overlay behind the drawer
innerClass string 'p-6' CSS classes to apply to the inner content container
preload boolean false Whether to preload the drawer content even when closed
focusOnHover boolean false Whether to show backdrop when hovering over drawer content (when enableBackdrop is false)

Outputs

Output Type Description
closeDrawer EventEmitter<void> Emitted when the drawer is closed via close button, backdrop click, or Escape key

Features

  • Multiple positions - Can be positioned on any side of the screen (top, right, bottom, left)
  • Resizable - Can be resized by dragging when the resizable option is enabled
  • Backdrop - Optional semi-transparent overlay that blocks interaction with content behind the drawer
  • Keyboard navigation - Can be closed with the Escape key
  • Custom sizing - Configurable initial size and min/max size constraints
  • Content projection - Can contain any content through Angular's content projection
  • Animations - Smooth slide-in/slide-out animations

Best Practices

  • Use drawers for temporary content or forms that need more space than a modal dialog
  • Choose the appropriate position based on your content and UI layout
  • Enable resizing when users might benefit from adjusting the drawer size
  • Disable the backdrop when you want users to be able to interact with content behind the drawer
  • For mobile layouts, consider using 'left' or 'right' positions with full or near-full width
  • Ensure your drawer content is properly structured with clear headings and actions
  • Include clear close actions, like a close button or cancel/submit buttons for forms
