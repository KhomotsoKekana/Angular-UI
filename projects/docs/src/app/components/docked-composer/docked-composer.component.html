Inputs

Input Type Default Description
isOpen boolean true Controls the visibility of the composer
title string 'New Message' Title displayed in the header of the composer
label string 'Customer' Secondary label for additional context (currently unused in UI)
allowClose boolean true Whether to show the close button
allowResize boolean true Whether to allow minimizing/maximizing the composer
allowDrag boolean false Whether the composer can be dragged around by its header

Outputs

Output Type Description
onClose EventEmitter<void> Emitted when the close button is clicked

Features

  • Minimizable - Collapse the composer to just its header
  • Maximizable - Expand the composer to take up more screen space
  • Closable - Completely hide the composer
  • Draggable - Optional ability to reposition the composer by dragging its header
  • Custom content - Project any content using Angular's content projection
  • Multiple instances - Support for multiple composers displayed simultaneously

Best Practices

  • Use composers for secondary operations that users might want to keep open while continuing to work with the main UI
  • Enable dragging for composers when users might benefit from repositioning them
  • Keep composer content focused on a single task or related set of actions
  • Consider accessibility by ensuring keyboard navigation works within your composer content
  • For multiple composers, use distinct titles to help users differentiate between them
