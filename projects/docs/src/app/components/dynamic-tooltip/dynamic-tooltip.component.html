Dynamic Tooltip Component

A flexible tooltip component that appears when a trigger element is hovered or clicked. The content of the tooltip is dynamically projected.

Properties (flex-dynamic-tooltip)

Property Type Default Description
tooltipPosition 'top' | 'bottom' | 'left' | 'right' 'top' Position of the tooltip relative to the trigger.
tooltipVariant 'default' | 'primary' | 'secondary' | 'ghost' | 'outline' | 'danger' | 'success' 'secondary' Predefined styling variant for the tooltip panel. (Note: custom content styling might override this)
trigger 'hover' | 'click' 'hover' Interaction that triggers the tooltip.
maxWidth string '300px' Maximum width of the tooltip content.
showDelay number 0 Delay in milliseconds before the tooltip is shown.
hideDelay number 50 Delay in milliseconds before the tooltip is hidden.

Structure

The dynamic tooltip is composed of three parts:

  • <flex-dynamic-tooltip>: The main wrapper component that orchestrates the tooltip behavior.
  • <flex-dynamic-tooltip-trigger>: Wraps the element that will trigger the tooltip.
  • <flex-dynamic-tooltip-content>: Wraps the content that will be displayed inside the tooltip. You can put any HTML structure here.

Accessibility Notes

Ensure that interactive elements within the tooltip content are keyboard accessible. The tooltip itself is managed using ARIA attributes for screen reader compatibility when using the CDK overlay.
