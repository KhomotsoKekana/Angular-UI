Card Component

A flexible container for displaying content in a clear, concise format.

Basic Card

Card Title

This is a simple card with some basic content. Cards can contain text, images, and other UI components.

With Custom Classes

Styled Card

This card has custom styling applied using the class input property.

Card with Header and Footer

Card Header

This card includes a header and footer section to organize content.

Card with Image

Card with Media

Cards can include images or other media content alongside text.

Usage

<!-- Basic card -->
<flex-card>
  <div class="p-6">
    <h3 class="text-lg font-medium">Card Title</h3>
    <p>Card content goes here.</p>
  </div>
</flex-card>

<!-- Card with custom styling -->
<flex-card class="border-2 border-blue-500 shadow-lg">
  <div class="p-6">
    <h3 class="text-lg font-medium">Styled Card</h3>
    <p>This card has custom styling.</p>
  </div>
</flex-card>

<!-- Card with header and footer -->
<flex-card>
  <div class="border-b p-4 bg-gray-50">Card Header</div>
  <div class="p-6">Card content</div>
  <div class="border-t p-4 bg-gray-50">Card Footer</div>
</flex-card>

Properties

Property Type Default Description
class string '' Custom CSS classes to apply to the card
