Accordion Component

An expandable panel component that can show and hide content.

This is the content of the first section. You can place any content here.

This accordion item is opened by default using the [defaultOpen] property.

You can add multiple paragraphs or any other components inside.

You can even include styled content within accordion items.

Properties

Property Type Default Description
title string '' The heading text for the accordion item
subTitle string '' Optional subtitle text displayed below the title
defaultOpen boolean false Whether the accordion item is expanded by default
