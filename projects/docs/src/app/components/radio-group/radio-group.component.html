Accessibility Notes

  • Radio buttons should be wrapped in <fieldset> with a descriptive <legend> for screen readers when used in forms
  • Each radio input should have a proper id and associated label with matching for attribute
  • Use aria-describedby to reference additional descriptive text if needed
  • Focus states should be clearly visible for keyboard navigation
