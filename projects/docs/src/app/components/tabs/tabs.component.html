Tab Properties

Property Type Default Description
label string undefined Display text for the tab
key string required Unique identifier for the tab, links to content component
leadingIcon string undefined Icon to display before the tab label
leadingStandardIcon string undefined Standard icon to display before the tab label
hidden boolean undefined Whether the tab should be hidden
group string undefined Group identifier for organizing tabs

Property Type Default Description

variant 'underline' | 'pill' | 'pill-square' | 'step' 'underline' Visual style for the tabs
lazyLoad boolean false Whether to only render tab content when it becomes active
