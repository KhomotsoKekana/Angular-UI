Main Sidebar Component

The <flex-main-sidebar> provides a collapsible navigation sidebar for applications. It supports icons, text labels, badges, and can be positioned on the left side of the screen. It also includes a responsive horizontal navigation bar for smaller screens.

The sidebar's state (collapsed/expanded) is managed internally by default but can be controlled. The navItems input takes an array of MainSidebarItem objects.

Component Inputs (<flex-main-sidebar>)

Property Type Default Description
width number 256 The width of the sidebar when it is expanded.
collapsedWidth number 56 The width of the sidebar when it is collapsed.
disabled boolean false Disables all interaction with the sidebar items if set to true.
navItems MainSidebarItem[] [] An array of navigation items to display in the sidebar. See MainSidebarItem interface below.

Interface: MainSidebarItem

Property Type Description
title string The text label for the navigation item. Will be translated.
url string The router link for the navigation item.
icon string The name of the icon to display (from the available icon set).
isActive boolean Indicates if the item is currently active. The component also updates this based on router events.
allowMobile boolean If true, this item will be shown in the bottom horizontal navigation on small screens.
position (optional) string If set to 'bottom', the item will be rendered in a separate group at the bottom of the sidebar.
hidden (optional) boolean If true, the item will not be rendered.
badge (optional) number A number to display as a badge on the navigation item.

Component Outputs (<flex-main-sidebar>)

Output Type Description
widthChange EventEmitter<number> Emits the new width of the sidebar when its collapsed state changes. This is not explicitly used in the component's own template but available for parent components.

Styling and Customization

The sidebar's appearance is primarily controlled by Tailwind CSS classes within its own component structure. You can customize the icons, colors (via button variants on nav items), and dimensions through its inputs. The flex-button component is used for individual navigation items, allowing for consistent styling. The active state is highlighted using the primaryGhost or primary variant of the button.

The responsive behavior for small screens (sm:hidden for vertical, flex sm:hidden for horizontal) is built-in. Ensure your application's icon set includes the icons specified in MainSidebarItem.icon.
