DropdownComponent Properties

Property Type Default Description
placement 'top' | 'bottom' | 'left' | 'right' 'bottom' Position of the dropdown menu relative to the trigger element
options [] Options for the dropdown (alternative to using dropdown-item)
placeholder string 'Select an option' Placeholder text when no option is selected
disabled boolean false Whether the dropdown is disabled
dynamicLookup boolean false Enable dynamic lookup functionality
dynamicLookupLoading boolean false Loading state for dynamic lookup

DropdownComponent Events

Event Type Description
selectionChange EventEmitter<any> Emitted when an option is selected
dynamicLookupValueChange EventEmitter<string> Emitted when the value changes in dynamic lookup mode

DropdownItemComponent Properties

Property Type Default Description
label string '' Text label for the dropdown item
description string undefined Optional description text
active boolean false Whether the item is active/selected
disabled boolean undefined Whether the item is disabled
class string '' Additional CSS classes to apply to the item

Accessibility

The Dropdown component follows accessibility best practices:

  • Uses proper focus management
  • Keyboard navigation support
  • ARIA attributes for screen readers
  • Visual indicators for active and disabled states
