Common Properties

Property Type Default Description
type 'bar' | 'line' | 'area' | 'donut' | 'radialBar' | 'pie' 'bar' Type of chart to display
title string '' Chart title
height number 320 Height of the chart in pixels
theme 'light' | 'dark' 'light' Chart theme
enableDataLabels boolean false Show data labels on the chart
valueFormatter (value: number) => string undefined Custom function to format values in labels and tooltips
legendPosition 'top' | 'bottom' | 'left' | 'right' 'top' Position of the legend

Best Practices

  • Use bar charts for comparing discrete categories
  • Use line charts for showing trends over continuous data points
  • Use area charts for emphasizing volume under a trend
  • Use donut/pie charts for showing proportion of parts to a whole
  • Provide value formatters to make data more readable
  • Keep colors consistent across related charts
  • Don't overload charts with too many data series
