OTP Input Component

A form control that allows users to enter One-Time Passwords.

Disabled OTP Input

Properties

Property Type Default Description
length number 6 The number of input fields for the OTP.
disabled boolean false Whether the OTP input is disabled.
placeholder string '' Placeholder character for empty inputs.
className string '' Custom CSS class for the component.

Events

Event Payload Description
otpChange string Emitted when the OTP value changes. The payload is the complete OTP string.

Usage

<app-otp-input
  [length]="6"
  placeholder="*"
  (otpChange)="handleOtpChange($event)">
</app-otp-input>
