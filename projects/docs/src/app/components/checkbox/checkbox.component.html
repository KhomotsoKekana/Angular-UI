Usage

<!-- Basic checkbox -->
<app-checkbox id="my-checkbox" [checked]="isChecked" (change)="onCheckboxChange($event)">
  Checkbox Label
</app-checkbox>

<!-- NgModel binding -->
<app-checkbox id="model-checkbox" [(ngModel)]="formValue">
  Two-way binding
</app-checkbox>

Properties

Property Type Default Description
checked boolean false Whether the checkbox is checked
id string 'checkbox' Unique identifier for the checkbox

Events

Event Payload Description
change { checked: boolean } Emitted when the checkbox state changes

Forms Integration

This component implements the ControlValueAccessor interface, making it compatible with Angular's form directives like ngModel and FormControl.
