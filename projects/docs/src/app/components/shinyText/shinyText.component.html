Shiny Text Component

A component that adds a shining animation to text.

Basic Usage

n This is some shiny text!

With Custom Class

This is larger, bold, purple shiny text!

Properties (flex-animated-shiny-text)

Property Type Default Description
className string '' Optional custom CSS classes to apply to the text.

Usage Example

<flex-animated-shiny-text className="text-xl text-blue-600">
  Hello World!
</flex-animated-shiny-text>
