Usage

<!-- Parent element needs positioning and structure -->
<div class="relative inline-flex">
  <!-- Element that triggers the tooltip -->
  <button (mouseenter)="tooltip.visible = true" 
          (mouseleave)="tooltip.visible = false">
    Hover Me
  </button>
  
  <!-- Container for positioning the tooltip -->
  <div class="absolute top-0 left-1/2 -translate-x-1/2 -translate-y-full">
    <!-- The tooltip component itself -->
    <flex-tooltip #tooltip 
      text="This is a tooltip"
      position="top"
      variant="default">
    </flex-tooltip>
  </div>
</div>

Properties

Property Type Default Description
text string '' Text content of the tooltip
position 'top' | 'bottom' | 'left' | 'right' 'top' Position of the tooltip relative to its target
bgColor string '#FFFFFF' Background color of the tooltip (when not using variants)
textColor string '#000000' Text color of the tooltip (when not using variants)
maxWidth string '200px' Maximum width of the tooltip
variant 'default' | 'primary' | 'secondary' | 'ghost' | 'outline' | 'danger' | 'success' 'default' Predefined styling variant for the tooltip
visible boolean false Controls the visibility of the tooltip

Accessibility Notes

For proper accessibility, tooltips should be used to provide non-essential information or clarification. Critical information should be made directly visible.

Using ARIA attributes such as aria-describedby on the trigger element linking to the tooltip's ID is recommended for screen reader compatibility.
