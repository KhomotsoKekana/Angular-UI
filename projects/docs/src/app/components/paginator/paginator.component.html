Properties (flex-custom-paginator)

Property Type Default Description
totalItems number 0 Total number of items to be paginated.
pageSize number 5 Number of items to display per page.
pageSizeOptions number[] [5, 10, 25, 50, 75, 100] Array of page size options for the user to select.

Events (flex-custom-paginator)

Event Payload Description
pageChange Emitted when the page index or page size changes.
