Badge Component

A small label that highlights status, count, or contextual information.

Variants

Sizes

Closable

With Numbers

Used as Wrapper

Custom Content

Usage

<!-- Basic badge -->
<app-badge 
  variant="success" 
  text="New Feature" 
/>

<!-- Closable badge -->
<app-badge 
  variant="error" 
  text="Outdated" 
  [closable]="true"
  (onClose)="handleBadgeClose()" 
/>

<!-- Number badge -->
<app-badge 
  variant="info" 
  [text]="unreadCount" 
/>

<!-- Badge as wrapper -->
<app-badge 
  variant="primary" 
  [isWrapper]="true"
>
  <span>Custom content</span>
</app-badge>

Properties

Property Type Default Description
variant 'success' | 'warning' | 'error' | 'neutral' | 'info' | 'primary' 'neutral' Determines the color and style of the badge
size 'xs' | 'sm' | 'md' | 'lg' 'sm' Controls the size of the badge
closable boolean false Whether the badge shows a close button
text string | number '' Text content of the badge
isWrapper boolean false Whether the badge wraps custom content

Events

Event Description
onClose Emitted when the close button is clicked
