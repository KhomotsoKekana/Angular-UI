Secondary Sidebar Component

The <flex-secondary-sidebar> provides a vertical navigation menu, typically used for sub-sections within a larger page or module (e.g., settings pages). It supports nested navigation items and displays a title.

1. Basic Secondary Sidebar

A simple secondary sidebar with a title and a flat list of navigation items. The title input sets the header for the sidebar, and navItems provides the links.

Content for the selected section would appear here.

<!-- component.html -->
<ui-secondary-sidebar [navItems]="myNavItems" [title]="'My Sidebar Title' | translate"></ui-secondary-sidebar>

<!-- component.ts -->
basicNavItems = [
  &#123; title: 'SIDEBAR.PROFILE', url: '/profile', icon: 'user', isActive: false, subItems: [] &#125;,
  &#123; title: 'SIDEBAR.ACCOUNT', url: '/account', icon: 'settings', isActive: true, subItems: [] &#125;,
  &#123; title: 'SIDEBAR.APPEARANCE', url: '/appearance', icon: 'eye', isActive: false, subItems: [] &#125;
];

2. Sidebar with Sub-Navigation

Demonstrates a sidebar with nested navigation items. Parent items expand to show their sub-items. The active state is managed based on the current route or manual interaction.

Content for the selected sub-section would appear here.

Selected: {{ item.title | translate }} > {{ subItem.title | translate }} 

<!-- component.html -->
<ui-secondary-sidebar [navItems]="navItemsWithSub" [title]="'Advanced Settings' | translate"></ui-secondary-sidebar>

<!-- component.ts -->
navItemsWithSub = [
  &#123;
    title: 'SIDEBAR.GENERAL', url: '/general', icon: 'settingsCog', isActive: false,
    subItems: [
      &#123; title: 'SIDEBAR.LANGUAGE', url: '/general/language', isActive: false &#125;,
      &#123; title: 'SIDEBAR.TIMEZONE', url: '/general/timezone', isActive: false &#125;
    ]
  &#125;,
  &#123;
    title: 'SIDEBAR.USERS', url: '/users', icon: 'users', isActive: true,
    subItems: [
      &#123; title: 'SIDEBAR.ALL_USERS', url: '/users/all', isActive: true &#125;,
      &#123; title: 'SIDEBAR.ROLES', url: '/users/roles', isActive: false &#125;
    ]
  &#125;
];

Component Inputs (<flex-secondary-sidebar>)

Property Type Default Description
title string 'Settings' The title displayed at the top of the sidebar. Can be a translation key.
navItems NavItem[] [] (empty array) An array of navigation items to display. See the NavItem interface below for structure.

Interface: NavItem

Each object in the navItems array should conform to the following structure:

Property Type Required Description
title string Yes The display text for the navigation item. Can be a translation key.
url string Yes (if no subItems or if parent is clickable) The router link for the navigation item.
icon string No The name of the icon to display (from the available icon set).
isActive boolean No Indicates if the item is currently active. The component also updates this based on router events.
subItems SubNavItem[] No An array of SubNavItem objects for nested navigation. See SubNavItem interface below.

Interface: SubNavItem

Each object in a NavItem's subItems array should conform to this structure:

Property Type Required Description
title string Yes The display text for the sub-navigation item. Can be a translation key.
url string Yes The router link for the sub-navigation item.
isActive boolean No Indicates if the sub-item is currently active. Updated based on router events.

Styling and Customization

The secondary sidebar's appearance is primarily controlled by Tailwind CSS classes within its own component structure and the flex-button component it uses internally. Active states are highlighted (e.g., text color, background). The component is designed to fit within a layout container and will take the height of its parent. Ensure your application's icon set (via IconComponent) includes any icons specified in NavItem.icon.
