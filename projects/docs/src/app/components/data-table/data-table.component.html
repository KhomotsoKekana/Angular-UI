Data Table Component

A powerful, feature-rich table component for displaying structured data with sorting, filtering, and pagination.

Client-side Data Processing

Server-side Data Processing

Usage

<!-- Basic client-side table -->
<app-data-table
  [data]="yourDataArray"
  [columns]="yourColumnsArray">
</app-data-table>

<!-- Server-side data processing with pagination, sorting, and filtering -->
<app-data-table
  [data]="serverData"
  [columns]="tableColumns"
  [isServerSide]="true"
  [loading]="loading"
  [totalItems]="totalItems"
  [pageSize]="pageSize"
  [pageIndex]="currentPage"
  (pageChange)="onPageChange($event)"
  (sortChange)="onSortChange($event)"
  (filterChange)="onFilterChange($event)">
</app-data-table>

<!-- With custom column templates -->
<app-data-table [data]="data" [columns]="columns">
  <ng-template appColumnTemplate columnName="status" let-element>
    <span class="badge" [ngClass]="element.status === 'Active' ? 'bg-green-500' : 'bg-red-500'">
      {{ element.status }}
    </span>
  </ng-template>
</app-data-table>

Column Definition Interface

export interface Column {
  name: string;         // Property name in data object
  header: string;       // Display name for column
  sortable?: boolean;   // Whether the column can be sorted
  filterable?: boolean; // Whether the column can be filtered
  cell?: (element: any) => string; // Optional formatter
  width?: string;       // Optional width specification
  align?: 'left' | 'center' | 'right'; // Alignment
  hideOnSmall?: boolean; // Hide on small screens
}

Properties

Property Type Default Description
data any[] [] Array of data objects to display in the table
columns Column[] [] Array of column definitions
isServerSide boolean false Whether data processing happens on the server
totalItems number 0 Total number of items for server-side pagination
pageIndex number 0 Current page index (0-based)
pageSize number 10 Number of items per page
pageSizeOptions number[] [5, 10, 25, 50, 100] Available page size options
loading boolean false Whether the table is loading data
rowClickable boolean false Whether rows can be clicked

Events

Event Payload Description
pageChange PageEvent Emitted when page index or size changes
sortChange Sort Emitted when sorting changes
filterChange TableFilter[] Emitted when filters are applied or cleared
rowClick any Emitted when a row is clicked (if rowClickable is true)
